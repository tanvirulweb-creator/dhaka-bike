# 🏍️ ঢাকা বাইক রাশ ৩ডি | Dhaka Bike Rush 3D

যাত্রাবাড়ী থেকে প্রগতি সরণি ও কুড়িল ফ্লাইওভার হয়ে উত্তরা হাউস বিল্ডিং পর্যন্ত ১২ কিলোমিটারের এক শ্বাসরুদ্ধকর রোবলক্স ৩ডি ব্রাউজার বাইক রেসিং গেম!

---

## 🌟 গেমের ফিচারসমূহ (Game Highlights)
* **🗺️ খাঁটি ঢাকা সিটির ১২ কিমি জিপিএস রুট:**
  1. **যাত্রাবাড়ী টু সায়েদাবাদ:** টার্মিনাল ট্র্যাফিক ও বাস জ্যাম।
  2. **প্রগতি সরণি (বাড্ডা / যমুনা ফিউচার পার্ক):** রাইদা ও অনাবিল লোকাল বাস ওভারটেকিং।
  3. **কুড়িল ফ্লাইওভার:** এলিভেটেড ফ্লাইওভারে হাই-স্পিড রাইডিং।
  4. **বিমানবন্দর সড়ক:** চার লেনের এক্সপ্রেসওয়ে ও আকাশে বিমান ওড়ার দৃশ্য।
  5. **উত্তরা হাউস বিল্ডিং:** মাথার ওপর মেট্রোরেলের লাইন ও ফাইনাল ফিনিশ লাইন!
* **🧱 রোবলক্স ৩ডি নান্দনিকতা (Roblox 3D Aesthetic):**
  * থ্রিডি স্পোর্টস বাইক ও হেলমেট পরা রোবলক্স বাইকার (টার্ন নেওয়ার সময় কাত হয়)।
  * সবুজ সিএনজি (আইকনিক গ্রিন বডি, হলুদ ছাদ ও লোহার খাঁচা)।
  * লোকাল মুড়ির টিন বাস (রাইদা, অনাবিল ও তুরাগ বাস)।
  * ঐতিহ্যবাহী রিকশা ও লুঙ্গি পরা রিকশাওয়ালা মামা।
* **📢 খাঁটি ঢাকার হর্ন মেকানিক্স:**
  * স্পেসবার বা হর্ন বাটন চাপলে বাইকের পীপ-পীপ হর্ন বাজবে এবং সামনের রিকশা ভয় পেয়ে সাইড দিয়ে দেবে!
* **☕ টংয়ের লাল চা (Nitro Boost):**
  * চা খেলে ৬ সেকেন্ডের জন্য সুপার স্পিড (১২০ কিমি/ঘণ্টা) এবং সব ভেঙে সামনে যাওয়ার ইনভিন্সিবিলিটি!
* **🔥 নিয়ার মিস (Near Miss) বোনাস:**
  * তীব্র গতিতে বাসের গা ঘেঁষে গেলে পাওয়া যাবে এক্সট্রা বোনাস পয়েন্ট!
* **🎵 ওয়েব অডিও সিন্থেসাইজার:**
  * কোনো এক্সটার্নাল MP3 ফাইলের ঝামেলা নেই; বাইকের ইঞ্জিনের গর্জন, হর্ন, কয়েন আর ক্র্যাশের সাউন্ড ব্রাউজারে স্বয়ংক্রিয়ভাবে সিন্থেসাইজ হয়।

## 🎮 কীভাবে খেলবেন (Controls)
* **⬅️ / ➡️ বা A / D:** ডানে বা বামে লেন পরিবর্তন
* **⬆️ / W:** এক্সিলারেটর (গতি বাড়ানো)
* **⬇️ / S:** ব্রেক (গতি কমানো)
* **Space / H:** হর্ন বাজানো
* **মোবাইল:** স্ক্রিনের অন-স্ক্রিন টাচ বাটন ব্যবহার করুন

## 🚀 GitHub ও Vercel-এ লাইভ করার নিয়ম (Deploy to Vercel)

### ধাপ ১: GitHub-এ রিপোজিটরি তৈরি ও পুশ করুন
আপনার টার্মিনালে এই কমান্ডগুলো চালান:

```bash
cd /Users/macbook/.gemini/antigravity/scratch/dhaka-bike-rush
git init
git add .
git commit -m "Initial commit - Dhaka Bike Rush 3D"
```

এখন [github.com](https://github.com)-এ গিয়ে একটি নতুন রিপোজিটরি তৈরি করুন (যেমন `dhaka-bike-rush`) এবং লিংক করুন:

```bash
git remote add origin https://github.com/<your-username>/dhaka-bike-rush.git
git branch -M main
git push -u origin main
```

### ধাপ ২: Vercel-এ ডিপ্লয় করুন
1. [vercel.com](https://vercel.com)-এ লগইন করুন।
2. **"Add New..."** বাটনে ক্লিক করে **"Project"** সিলেক্ট করুন।
3. আপনার GitHub-এর `dhaka-bike-rush` রিপোজিটরিটি সিলেক্ট করে **Import** চাপুন।
4. Framework Preset-এ **Vite** সিলেক্ট থাকবে। সরাসরি **"Deploy"** বাটনে ক্লিক করুন!
5. মাত্র ১ মিনিটে আপনার গেমটি লাইভ হয়ে যাবে এবং বন্ধুদের সাথে শেয়ার করার জন্য একটি ফ্রি লিংক (যেমন `https://dhaka-bike-rush.vercel.app`) পেয়ে যাবেন!
